# Backlog: calculations and table calculations

Built: calculated fields with `+ − * /` and `SUM`/`AVG`/`MIN`/`MAX`/`COUNT`/`COUNTD`/`MEDIAN`/`STDDEV`/`VARIANCE`/`PERCENTILE`/`ATTR` over fields; text functions (`LOWER`, `UPPER`, `TRIM`, `LEN`, `LEFT`, `RIGHT`, `REPLACE`, `CONCAT`, `CONTAINS`, `STARTSWITH`, `ENDSWITH`, `SPLIT`); date functions (`DATEDIFF`, `DATEADD`, `YEAR`, `MONTH`, `DAY`, `QUARTER`, `WEEK`, `WEEKDAY`, `DATE`); plain measures also have median, standard deviation, variance and ATTR ([calculated-fields.md](../features/calculated-fields.md)). Entries are in dependency order. Format: [README.md](README.md#how-to-read-an-entry). Every new function goes through the whitelisted expression tree, never formula text on the server. The endpoint also takes LOD terms, extra join types and a function whitelist, with the same limits and response shape; it never accepts SQL text.
