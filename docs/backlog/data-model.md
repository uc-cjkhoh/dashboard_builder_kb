# Backlog: data model and data source

Today relationships are logical, inner/left/right/full, one equality pair each ([relationships.md](../features/relationships.md)). Entries are in dependency order. A union compiles to `UNION ALL` with explicit column alignment; unpivot and split compile to ClickHouse array and string functions; source tables are never altered, and null, empty string, zero, invalid date and non-finite number stay distinct. Format: [README.md](README.md#how-to-read-an-entry).

- **Compound joins and key suggestion** (IDs: T02-14, T02-15; priority P2) — Open: manual single-pair equality only; no matching-name suggestion. Needs: none.
- **Union: remainders** (IDs: T02-16; priority P1) — Partial: a bounded preview of 2–5 tables stacked over their shared columns is built ([schema-browser.md](../features/schema-browser.md#union)). Open: a union can't be used as a data source (no canvas entity, no worksheet fields, no query); columns are matched by name and kind only (no manual alignment of differently named columns, no rename, no mismatched-fields view); no filters; tables of one database only. Needs: a union as a query source in `/api/query`.
- **P43 Many-to-many and two-way relationships** (priority P1; effort M) — Open: cardinality is recorded but every link joins inner, one way. Aggregate each side to the shared key before joining so measures do not double-count; add a per-relationship filter direction. Needs: none (join types are built).
- **Member labels and groups: remainders** (IDs: T02-29, T02-30; priority P2) — Partial: member labels (display-side) and text-field groups, with an "Other" label for ungrouped members (a generated calculation tree), are built ([worksheet.md](../features/worksheet.md#layout), [calculated-fields.md](../features/calculated-fields.md#group-fields)). Open: groups on number, date and true/false fields (the engine compares text only; numeric ranges and date bins would need `IN` / range nodes); more than 49 members across a field's groups (48 with the "Other" label; the 200-node limit; needs an `in` node on the server); a way to group NULL (the remainder label leaves NULL empty); making a group from the marks selected on a chart (Tableau's group icon); labels for calculated and group dimensions, date-part keys, bucketed numeric keys and Pages; groups on UUID, IP and enum columns (a `toString` branch), and a selection chip that follows a label edit; one label set shared by a field's group field and the field. Needs: none.
- **Split and unpivot: remainders** (IDs: T02-31, T02-32; priority P1) — Partial: a text field's **Split…** makes one `SPLIT` calculated field per piece ([calculated-fields.md](../features/calculated-fields.md#text-functions)); a bounded **unpivot preview** of wide same-kind columns of one table is built ([schema-browser.md](../features/schema-browser.md#unpivot)). Open: an unpivot can't be used as a data source (no canvas entity, no worksheet fields `Field` / `Value`, no query); no unpivot of mixed-kind columns, no rename of `Field` / `Value`, no pivot back; a split is a fixed separator and piece count (no split on a pattern or by position, no "split into rows", no rule to name pieces, the piece count is not discovered from the data); Split on a field of a multi-table model is by one column only. Needs: an unpivot as a query source in `/api/query` (with the union's).
- **Expand / collapse headers** (IDs: T03-29; priority P1) — Named, reusable hierarchies and the Drill tool are built ([worksheet-encodings.md](../features/worksheet-encodings.md#named-hierarchies)). Open: crosstab row / column headers can't be expanded or collapsed in place (a +/- on a header showing or hiding the next level); a sheet's drill is a copy, so editing a hierarchy doesn't update sheets that used it; no hierarchy on calculated or cast fields, and no multi-table hierarchy. Needs: none.
- **Field details** (IDs: T02-33; priority P2) — Partial: the column profile dialog shows name, type, kind, role and copies the name or top values ([schema-browser.md](../features/schema-browser.md#column-profile--field-details)); copying a field's name or formula from the worksheet field list is built ([worksheet.md](../features/worksheet.md)). Open: no editable field properties (default sort, semantic role). Needs: none.
- **Query-time cleaning** (priority P1) — open: trim, recode, date construction and replace-null as field metadata or calculated fields; there are no prep flows, materialised output or saved flows (see [out-of-scope.md](out-of-scope.md)). Needs: text, logic and date functions in [calculations.md](calculations.md).
