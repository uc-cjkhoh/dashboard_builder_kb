# Backlog: charts, authoring and formatting

Chart, authoring and formatting work not yet built. Format: [index.md](index.md#how-to-read-an-entry). Built chart types are in [worksheet-charts.md](../../concepts/worksheet/worksheet-charts.md).

## Chart gaps

- **Continuous time axis, gap filling and true jump lines** (IDs: T03-05 remainder, T03-07; priority P1) — Open: a true jump line (disconnected horizontal segments with no risers, as in Tableau; the current Step (centred) is a connected step); lines sit on a category axis, so unevenly spaced dates are drawn evenly and missing periods are not filled. Partial: discrete and truncated date parts exist; no continuous time axis or gap filling. Needs: none.
- **Layered marks and dual axis beyond line, area and the combo** (IDs: T03-16 remainder, T03-17 remainder; priority P2) — Partial: the combo and Line / Area (Format → Dual axis) put measures on a right axis with Synchronise axes. Open: a dual axis on scatter; independent mark types per measure (all right-axis measures share one type, and line / area have no right-axis mark choice); a user-set axis range or a synchronise that spans a field the chart does not plot. Needs: none.
- **Density mark and Gantt remainders** (IDs: T03-14 remainder; priority P2) — Partial: Gantt draws one bar per member from a start measure and a length measure (date start counts days). Open: no density surface; a Gantt length from an end field, a colour split per bar, dependencies, and click-to-filter. Needs: none.
- **Colour, size and shape beyond current marks** (IDs: T03-19, T03-20, T03-21, T01-21; priority P1) — Partial: continuous colour works on scatter, heatmap and table, with a hue choice, a pinned range, a Diverging scale and a Steps choice (3 to 9 discrete steps, boundaries named in the legend) on scatter and heatmap (Format); shape works on scatter only; size on scatter bubbles only. Open: continuous and stepped colour on bars, lines, treemap and the other types (Steps is wired for scatter and heatmap only; the table scale has its own rules); size on line markers, bars and treemap; shape beyond scatter. Needs: none.
- **Palette editing and member-colour gaps** (IDs: T01-20 and T03-24 remainder, T03-33 remainder; priority P1) — Partial: diverging continuous colour (a centre value, fixed orange / blue tokens) is built for heatmap and scatter. Open: a chosen pair of diverging hues; custom palette editing and a free-hex picker (only 24 fixed swatches); member colours cannot be set from the legend (a legend click highlights), cannot be assigned to scatter groups, treemap or funnel members, and are unsupported for calculated fields; no reversed-per-field ramps. Needs: none.
- **Marker and border refinements** (IDs: T01-22 remainder, T03-34 remainder; priority P2) — Partial: Format has a marker size (4–40 px), a marker shape on line charts, and a none / thin / thick mark border (in the muted ink) for scatter, line markers, circle heatmap, bars, cells, pie, treemap and funnel. Open: a border on the P36 types (box plot, bullet, gauge, waterfall, histogram and the rest); a border colour or width of the user's choosing (from the palette tokens); per-series marker size and shape. Needs: none.
- **Measure-filter remainders and a range slider** (IDs: T03-27 remainder; priority P2) — Partial: a measure pill carries a number condition on its aggregated value (SQL `HAVING`, [D84](../../decisions/decisions-filters.md#d84--a-filter-on-an-aggregated-measure-having-keeps-groups-after-grouping)). Open: a range slider (the condition is typed); a filter on a measure that isn't on the view, on a Top-N ranking measure, or on a Size / Colour / Label measure; a filter shared across dashboards; the Other bucket together with a measure filter; histogram and box plot. Needs: none.

## Authoring gaps

- **Tooltip token styling** (IDs: T01-19 remainder; priority P3) — per-field number / date formats are built; missing: styling a single field token or word within a line (size / bold / italic / colour are per line today). Needs: none.
- **Continuous dates** (IDs: T01-04; priority P1) — partial: a number toggles Continuous (measure) / Discrete (dimension) from its pill popup. Missing: a Continuous / Discrete choice for a date pill (a date part still picks the grouping; the choice needs the true continuous time axis and jump lines, which are a separate backlog item). Needs: none.
- **Start screen and recent sources** (IDs: T01-14; priority P1) — partial: import, autosave restore and recent connections (host, port, user; no password) exist; no start screen listing recent workbooks or sample data. Needs: none.
- **Analytics pane** (IDs: T07-01; priority P2) — partial: the Analytics card has draggable / pressable items (reference line, band, trend, forecast) that add at a default; missing: a separate always-visible pane, items placed per measure or per chart (a line sits on one chosen measure), and items for a table (totals stay checkboxes). Needs: none.
- **Performance recording, remainder** (IDs: T01-30; priority P2) — the timing log and Performance dialog are built for worksheet queries and draws; missing: table scroll pages, comparison queries and failed / aborted queries are not recorded, and there is no server-side timing. Needs: none.
