# Changelog

Change history is generated, never hand-edited. The KB itself tracks current state only.

- [Feature updates](docs/development/updates/feature_updates.md) — functional changes (server, models, validation, calculations, charts, workbook), by date.
- [UI updates](docs/development/updates/ui_updates.md) — visual and interaction changes, by date.

Both are rebuilt from the app repo's `main` history by `.claude/hooks/update-log.py` ([hooks.md](docs/development/hooks.md)).
